# Bot Questões

Extensão que responde exercícios de múltipla escolha usando a IA Gemini. Chrome e Firefox.

## Baixar

```bash
git clone https://github.com/d4nielantoni/bot-questoes.git
```

Ou **Code → Download ZIP** e descompacte. A pasta precisa continuar existindo: o navegador lê dela, não copia os arquivos.

## Instalar

**Chrome** — `chrome://extensions` → Modo do desenvolvedor → Carregar sem compactação → escolha **a pasta**.

**Firefox** — `about:debugging#/runtime/this-firefox` → Carregar extensão temporária → escolha o **`manifest.json`**. Some ao fechar o navegador. Requer Firefox 113+.

## Usar

1. Pegue uma chave gratuita em [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Clique no ícone da extensão, cole a chave e salve
3. Abra o exercício e clique em **Resolver quiz**, no canto inferior direito

A chave fica só no seu navegador. O bot marca as alternativas; enviar é decisão sua. Erros aparecem no próprio botão.
